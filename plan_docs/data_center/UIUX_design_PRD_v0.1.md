> 결정 전제(사용자 확정): ① 게이트 허브 = `/` · ② 카탈로그+필터 다운로드(CSV/GeoJSON) · ③ Hyperbeat 미학 강화
> rev 메모(2026-06-13): **기상청 단기예보(SMB)** 를 데이터센터 카탈로그에 포함 — DB 테이블이 아닌 **파일 소스(`source:"file"`)** 로, CSV 다운로드만. (연동 방식은 아키텍처 §7.5)

## 1. 개요 & 목표

Energy-Hub 를 **"지도 대시보드"** 단일 진입에서 → **"진입 게이트 → 2개 도메인(지도 / 데이터센터)"** 구조로 확장한다.

| 목표 | 설명 |
|------|------|
| G1. 명확한 분기 | 앱 진입 즉시 두 갈래(데이터 받기 / 지도 보기)를 1초 안에 인지·선택 |
| G2. 데이터 개방 | DB 로컬 테이블을 **카탈로그 → 필터 → 미리보기 → CSV/GeoJSON 내보내기** 흐름으로 셀프서비스 다운로드 |
| G3. 미학 일관성 | 기존 Hyperbeat(터미널/오더북) 언어를 **깨지 않고 강화**. 마케팅 랜딩페이지 금지 |
| G4. 구현 깔끔함 | 신규 화면은 독립 라우트 + feature 폴더로 분리, MapView 류 거대 컴포넌트 재발 방지 (→ 아키텍처 문서) |

**Non-goal**: 회원/로그인, 결제, 마케팅 히어로·스크롤 텔링, 외부 공유.

## 2. 정보구조 (IA) & 라우팅 맵

```
/                → GateHubPage     [신규]  미션컨트롤 분기 게이트 (버튼 2개)
/map             → MainPage        [기존]  지도 대시보드 (경로만 / → /map 이동)
/data            → DataCenterPage  [신규]  마이크로 데이터센터 (다운로드)
/twin/jeju       → JejuTwinPage    [기존]  유지
*                → redirect → /            (게이트로 회수)
```

- 게이트는 **풀스크린이되 "랜딩"이 아니다** — 스크롤 없음, 카피·CTA·일러스트 없음. 한 화면에서 끝나는 *분기 콘솔*.
- 게이트 ↔ 지도/데이터센터 사이는 **얇은 글로벌 바**로 항상 상호 이동 가능(2장 §6).

## 3. 디자인 컨셉 — "MISSION CONTROL 분기 게이트"

> 한 줄 컨셉: *발전소 관제실의 메인 콘솔 앞에 선 느낌.* 검정 배경 위 모노스페이스 텔레메트리, 좌/우로 갈라지는 두 개의 게이트 패널.

기억에 남는 단 하나(Differentiation): **화면 중앙 수직 분할선(seam)** 을 따라 흐르는 가는 스캔라인. 좌(DATA)·우(MAP) 패널에 마우스를 올리면 그쪽으로 seam 의 광량이 쏠리며(글로우) 패널이 "활성"된다. 키보드 ←/→ 로도 포커스 전환.

- 톤: **industrial / utilitarian + terminal**. 장식 최소, 정보 밀도 높음, 정밀한 정렬.
- 모티프: 그리드 라인, 코너 브래킷(⌐ ¬ ⌙ ⌐), 모노스페이스 라벨, 점멸 캐럿(`▌`), 헤어라인 보더.
- 절대 회피: 보라색 그라데이션, 둥근 카드+드롭섀도우 SaaS 룩, 일러스트 스팟, Inter 를 히어로로 쓰기.

## 4. 디자인 토큰

### 4.1 기존 토큰 재사용 (변경 없음)
`tailwind.config.js` / `globals.css` 의 Hyperbeat 토큰을 **그대로** 사용한다.

| 역할 | 토큰 |
|------|------|
| 배경/표면/패널 | `hb-bg` `hb-surface` `hb-panel` (다크: `#0b0b0e`/`#111116`/`#16161d`) |
| 보더 | `hb-border` `hb-border-light` |
| 텍스트 | `text-primary` `text-secondary` `text-muted` `text-label` |
| 액센트 | `accent-green #0ecb81` · `red #f6465d` · `blue #2962ff` · `cyan #00b8d9` · `amber #f0b90b` |
| 폰트 | `font-mono` (IBM Plex Mono) · `font-sans` (Inter) |

### 4.2 게이트 전용 추가 토큰 (`globals.css` 에 신설, 게이트 스코프)

```css
@layer components {
  /* 게이트 도메인별 시그니처 컬러 */
  --gate-data: theme(colors.accent.cyan);   /* 데이터센터 = cyan */
  --gate-map:  theme(colors.accent.green);  /* 라이브 맵   = green */

  /* 디스플레이 보이스: IBM Plex Mono 를 히어로 타이포로 승격 (신규 폰트 의존성 X) */
  .gate-display { @apply font-mono uppercase tracking-[0.18em]; }
  .gate-seam    { /* 중앙 수직 스캔라인 */ }
}
```

- **폰트 결정**: 새 웹폰트를 추가하지 않는다. 이미 로드된 **IBM Plex Mono** 를 게이트의 *디스플레이/히어로* 보이스로 승격 → 터미널 정체성 강화 + 번들 증가 0 + 코히전 유지. (frontend-design 의 "Inter 를 히어로로 쓰지 말 것" 가이드와 정합)
- 본문/보조 텍스트는 기존 Inter 유지.

## 5. 게이트 허브 (`/`) 화면 설계

### 5.1 레이아웃 (데스크톱 ≥ 1024px)

```
┌───────────────────────────────────────────────────────────────┐
│  ENERGY-HUB ▌ CONTROL                       2026-06-13 03:42 UTC│  ← 텔레메트리 바 (h-9)
├──────────────────────────────┬────────────────────────────────┤
│  ⌐                          ¬ │ ⌐                            ¬  │
│   MICRO DATA CENTER           │   LIVE MAP                      │
│   01 / DATASET EXPORT         │   02 / GEOSPATIAL DASHBOARD     │
│                               │                                 │
│   PV · 변전소 · 토지피복       │   114,840 PV · 1,185 변전소     │  ← 실데이터 미리수치
│   EV · 발전량 · 수요 · 통계    │   FDW 실시간 수요·발전량        │     (catalog/stats API)
│                               │                                 │
│   CSV · GeoJSON 내보내기       │   벡터타일 · 클러스터 · 트윈     │
│                               │                                 │
│   [ ENTER  → ]                │   [ ENTER  → ]                  │  ← 모노스페이스 버튼
│  ⌙                          ⌐ │ ⌙                            ⌐  │
└──────────────────────────────┴────────────────────────────────┘
            ▲ 중앙 seam (1px, 스캔라인 애니메이션, hover 시 글로우 이동)
```

- **2분할 (50/50)**: 좌 = 데이터센터(cyan), 우 = 라이브 맵(green). 각 패널은 `<button>`/`<a>` 시맨틱, 전체가 클릭 타깃.
- 각 패널 4모서리 **코너 브래킷**, 헤어라인 보더(`hb-border`). hover/focus 시 해당 도메인 액센트로 보더·브래킷·`ENTER` 글로우.
- 상단 **텔레메트리 바**(h-9): 좌측 워드마크 `ENERGY-HUB ▌ CONTROL`, 우측 실시간 시계(UTC) + 빌드 버전. 기존 `TopBar` ticker 스타일 차용.
- 패널 내부 **미리수치**는 카피가 아니라 *데이터*다: `/data/catalog`(총 데이터셋·행수)와 `/stats/summary`(PV/변전소 카운트)에서 받아 모노스페이스로 표기 → "마케팅 문구" 대신 "관제 수치".

### 5.2 인터랙션 / 모션
- **로드**: seam 이 위→아래로 그어지며(200ms) 좌·우 패널이 바깥에서 안으로 staggered 등장(좌 0ms, 우 80ms). 텔레메트리 수치는 `count-up` 없이 즉시(과한 연출 금지).
- **hover/focus**: 해당 패널 보더+브래킷 액센트 점등, seam 글로우가 그쪽으로 60% 쏠림, `ENTER →` 의 캐럿 `→` 가 4px 우측 슬라이드.
- **키보드**: `←/→` 패널 포커스, `Enter` 진입. 탭 순서 = 데이터센터 → 맵.
- **전환**: 선택 시 해당 패널이 가로로 확장(220ms ease-out)하며 라우트 이동(`navigate('/data' | '/map')`). 과장된 페이지 트랜지션 금지.
- 모션 라이브러리 미도입 — **CSS transition/keyframes 로만** 구현(번들·복잡도 최소). `prefers-reduced-motion` 시 모든 모션 off, 즉시 표시.

### 5.3 반응형
| 폭 | 레이아웃 |
|----|----------|
| ≥ 1024px | 좌/우 50/50 수직 분할 (위 그림) |
| 640–1023px | 상/하 스택, seam 은 수평선 |
| < 640px | 풀폭 카드 2개 세로 스택, 코너 브래킷 유지, 텔레메트리 바 압축 |

## 6. 마이크로 데이터센터 (`/data`) 화면 설계

### 6.1 레이아웃 — 3존 콘솔

```
┌───────────────────────────────────────────────────────────────┐
│  ← BACK  │ MICRO DATA CENTER         [지도로 →]   2026-06-13    │  글로벌 바 (h-10)
├───────────────┬───────────────────────────────────────────────┤
│ DATASETS      │  FILTERS                          EXPORT        │
│ (catalog)     │  ┌─────────────────────────────┐  ┌─────────┐ │
│ ▸ PV 발전소    │  │ 시도  [전체 ▾]               │  │ ROWS    │ │
│ ▸ 변전소       │  │ 기간  [2020-01]~[2026-06]    │  │ ~33,371 │ │
│ ▸ 토지피복     │  │ 용량  [0]──●────[max] kW     │  └─────────┘ │
│ ▸ EV 충전기    │  └─────────────────────────────┘  [ CSV  ↓ ]  │
│ ▸ 발전량       │                                    [ GeoJSON↓]│
│ ▸ 수요         │  PREVIEW (상위 50행)                          │
│ ▸ 통계         │  ┌─────────────────────────────────────────┐ │
│ ▸ 단기예보 ⎘   │  │ id │ name │ sido │ cap_kw │ status │ ...  │ │  ← ⎘=FILE 뱃지
│   [선택됨]     │  │ ... 오더북 스타일 행, tabular-nums ...    │ │
│               │  │ ... 오더북 스타일 행, tabular-nums ...    │ │
└───────────────┴───┴─────────────────────────────────────────┴─┘
   좌 사이드(w-64)        중앙 필터+미리보기                우상 export
```

- **존 A — 데이터셋 목록(좌, w-64)**: `/data/catalog` 결과. 각 항목 = 라벨 + 행수 + **소스/지오메트리 뱃지**(◇ POINT / ▦ POLYGON / — 비공간 / **⎘ FILE**=단기예보 등 파일 소스). 선택 시 cyan 활성 바.
- **존 B — 필터(중앙 상단)**: 데이터셋 카탈로그가 선언한 `filters` 스펙에 따라 **동적 렌더**(시도 select, 기간 range, 용량 slider 등). 하드코딩 금지 — 카탈로그 메타가 폼을 결정. 파일 소스(단기예보)는 같은 동적 폼에 **발표시각(base) select + 지역 select**(manifest 기반)가 렌더된다.
- **존 C — 미리보기(중앙 하단)**: `/data/{id}/preview?...` 상위 50행을 **오더북 스타일 테이블**(헤어라인 행 구분, 숫자 `tabular-nums`, 헤더 all-caps). 가상 스크롤 불필요(50행 고정). 파일 소스는 선택된 CSV 의 앞 50행을 동일 형식으로 표시.
- **존 D — 내보내기(우상)**: 예상 행수 카드 + `CSV ↓` / `GeoJSON ↓` 버튼. 비공간·파일 데이터셋은 GeoJSON 버튼 비활성. 클릭 시 현재 필터를 쿼리스트링으로 export URL 생성 → 브라우저 네이티브 다운로드(메모리 적재 X, 아키텍처 문서 §6·§7.5).

### 6.2 상태/엣지 케이스 (UI 표기)
| 상태 | 표기 |
|------|------|
| 카탈로그 로딩 | 좌측 스켈레톤 행(헤어라인 점멸) |
| 데이터셋 미선택 | 중앙에 `SELECT A DATASET ▌` 캐럿 점멸 placeholder |
| 미리보기 0행 | `NO ROWS MATCH FILTER` + 필터 리셋 링크 |
| export 진행 | 버튼 내 `STREAMING…` + 비활성, 완료 시 복귀 (Content-Disposition 으로 브라우저가 처리) |
| 예상 행 과다(>50만) | 행수 카드 amber + `대용량 — 압축 권장` 힌트 |
| API 오류 | 행 상단 red 헤어라인 + `EXPORT FAILED · {detail}` |

### 6.3 다운로드 UX 원칙
- 다운로드는 **현재 화면의 필터 상태와 100% 일치**해야 함(미리보기 = 받을 데이터의 표본).
- 파일명 규칙: `{dataset}_{sido|all}_{yyyymmdd}.{csv|geojson}` (서버 Content-Disposition 에서 지정).
- 진행률 바는 만들지 않음(스트리밍·브라우저 네이티브). 대신 시작/실패만 명확히.

### 6.4 단기예보 (파일 소스) 화면 차이

DB 데이터셋과 **동일한 3존 골격**을 쓰되, 소스가 파일(릴리스 CSV)이라 아래만 다르다. UI 분기는 `meta.source === "file"` 한 곳에 격리(아키텍처 §7.5.4).

| 존 | DB 데이터셋 | 단기예보(file) |
|----|-------------|----------------|
| A 뱃지 | ◇/▦/— | **⎘ FILE** |
| B 필터 | 시도/기간/용량 | **발표시각(base) ▾ + 지역 ▾** (manifest 기반) |
| C 미리보기 | 쿼리 상위 50행 | 선택 CSV 앞 50행 |
| D 내보내기 | CSV + GeoJSON | **CSV 만** (GeoJSON 비활성) |
| D 메타 | `ROWS ~N` | **`RELEASE 20260304T203000Z`** (출처 표기) + 파일 크기 |

- 존 D 우상단에 **`SOURCE: SMB RELEASE`** 라벨 + 릴리스 id 를 모노스페이스로 노출 → "실시간 쿼리"가 아니라 "검증된 릴리스 파일"임을 정직하게 표기(디자인 문서 G3, 트윈의 정직 라벨링 원칙과 동일 톤).
- 발표시각이 갱신되면(릴리스 스왑) 카탈로그가 새 base 옵션을 보여줌 — 프론트는 catalog 재요청만.

## 7. 글로벌 네비게이션 & 전환

- 게이트(`/`)를 제외한 모든 화면 상단에 **얇은 글로벌 바**: 좌 `← 게이트`, 중앙 현재 도메인 라벨, 우 상대 도메인 바로가기(`데이터센터 ⇄ 지도`).
- 기존 `MainPage` 의 `TopBar` 와 데이터센터 바는 **공통 `GlobalBar` 컴포넌트**로 통일(아키텍처 문서에서 컴포넌트화) → 시각·동작 일관성.
- 테마 토글(다크/라이트)은 글로벌 바 우측에 유지(기존 `localStorage('theme')` 로직 재사용).

## 8. 접근성 (a11y)
- 게이트 두 패널은 `role` 명확한 링크/버튼, `aria-label`(예: "마이크로 데이터센터로 이동").
- 키보드 완전 조작(←/→/Enter/Tab), 포커스 링은 도메인 액센트 2px.
- 명도 대비 ≥ 4.5:1 (모노 라벨은 `text-secondary` 이상 사용, `text-muted` 는 비핵심만).
- `prefers-reduced-motion`/`prefers-color-scheme` 존중.
- 데이터센터 테이블은 `<table>` 시맨틱 + `<th scope>`.

## 10. 수용 기준 (Acceptance Criteria)

- [ ] `/` 진입 시 스크롤 없이 한 화면에서 2개 분기가 즉시 보인다(랜딩 카피·히어로 없음).
- [ ] 게이트가 다크/라이트 양 테마에서 토큰만으로 일관되게 렌더된다.
- [ ] 키보드(←/→/Enter)만으로 두 도메인 진입 가능.
- [ ] 게이트 패널 수치가 실제 API(catalog/stats)에서 온다(하드코딩 금지).
- [ ] `/data` 에서 데이터셋 선택 → 필터 → 미리보기 50행 → CSV/GeoJSON 다운로드가 동일 필터로 일관된다.
- [ ] 비공간·파일 데이터셋은 GeoJSON 버튼이 비활성된다.
- [ ] 단기예보(파일 소스)가 ⎘ FILE 뱃지로 구분되고, 발표시각/지역 선택 → CSV 다운로드 + 릴리스 id 가 표기된다.
- [ ] `prefers-reduced-motion` 에서 모든 모션이 제거된다.
- [ ] 신규 화면이 기존 Hyperbeat 토큰·폰트만 사용(신규 웹폰트·보라 그라데이션 0).
